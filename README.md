## 🐍 Sobre o Projeto 

Este repositório serve como um portfólio do meu progresso e aprendizado acompanhando a obra "Curso Intensivo de Python: Uma introdução prática e baseada em projetos à programação". O material abrangerá desde conceitos fundamentais de programação até o desenvolvimento de aplicações práticas. 

## 🗂️ Estrutura do Repositório 

Os arquivos e códigos estão divididos nas duas grandes partes estruturais do livro: 

### Parte I: Noções Básicas 
Nesta parte, estão os arquivos correspondentes aos fundamentos e à base da linguagem Python: 
* **Capítulo 1:** Primeiros passos 
* **Capítulo 2:** Variáveis e tipos de dados simples 
* **Capítulo 3:** Introdução às listas 
* **Capítulo 4:** Trabalhando com listas 
* **Capítulo 5:** Instruções if 
* **Capítulo 6:** Dicionários 
* **Capítulo 7:** Entrada do usuário e loops while 
* **Capítulo 8:** Funções 
* **Capítulo 9:** Classes 
* **Capítulo 10:** Arquivos e exceções 
* **Capítulo 11:** Testando seu código 

### Parte II: Projetos 
A segunda parte reúne os três grandes projetos propostos para colocar a teoria em prática: 

**🎮 Projeto 1: Invasão Alienígena** - Desenvolvimento de um jogo no estilo Space Invaders utilizando Pygame. 
* **Capítulo 12:** Uma espaçonave que dispara balas 
* **Capítulo 13:** Alienígenas! 
* **Capítulo 14:** Pontuação 

**📊 Projeto 2: Visualização de Dados** - Geração, download e exibição de dados em diferentes formatos e de APIs, utilizando bibliotecas gráficas. 
* **Capítulos 15 a 17:** Compreende a geração, download de dados (como arquivos CSV e GeoJSON) e trabalho com APIs Web, usando Matplotlib e Plotly. 

**🌐 Projeto 3: Aplicações Web (Registro de Aprendizagem)** - Criação e implantação de um sistema web para contas de usuário registrar aprendizados. 
* **Capítulo 18:** Primeiros passos com o Django 
* **Capítulo 19:** Contas de usuário 
* **Capítulo 20:** Estilizando e fazendo o deploy de uma aplicação 

## 🛠️ Tecnologias e Ferramentas 

* **Linguagem Principal:** Python 
* **Editor:** VS Code 
* **Testes:** pytest 
* **Bibliotecas e Frameworks:** Pygame, Matplotlib, Plotly, Requests e Django.
